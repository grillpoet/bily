\# Bily



A lightweight Android client for Bilibili, focused on searching, playing, and downloading videos. Built with Kotlin and Jetpack Compose.



Features:

\- Search videos and browse creator spaces (UP主)

\- Audio/Video playback with gesture seek, speed control, and fullscreen

\- Download videos with quality selection (720P / 360P)

\- Favorites with custom folders and import/export support

\- Dark theme

\- Debug panel for network/error tracking



Tech Stack:

\- Kotlin + Jetpack Compose

\- Media3 (ExoPlayer) for playback

\- OkHttp + Kotlinx Serialization for networking

\- Coil for image loading

\- DataStore for preferences



Build:



`./gradlew assembleDebug`

\# Bily



Bily 是一个轻量的 Android Bilibili 客户端，用于搜索、播放和下载视频。基于 Kotlin 和 Jetpack Compose 开发。



功能：

\- 搜索视频，浏览 UP 主空间

\- 视频播放，支持手势快进、倍速、全屏切换

\- 视频下载，支持选择清晰度（720P / 360P）

\- 自定义收藏夹，支持导入导出

\- 深色模式

\- 内置调试面板，方便排查网络和报错



技术栈：

\- Kotlin + Jetpack Compose

\- Media3 (ExoPlayer) 播放

\- OkHttp + Kotlinx Serialization 网络请求

\- Coil 图片加载

\- DataStore 偏好存储



构建：



`./gradlew assembleDebug`
